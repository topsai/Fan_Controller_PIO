# State Machines

## 1. 发射端状态机

| 状态 | 进入条件 | 行为 | 退出条件 |
|---|---|---|---|
| 初始化 | 上电 | 初始化串口、引脚、OLED、CW2015、ESP-NOW、定时器，播放启动提示音 | 初始化流程完成 |
| 未连接 | 未收到合法状态包，或 500ms 未收到状态包 | 继续 100Hz 发送控制包；OLED 显示 `[LOST]`；蜂鸣器周期报警 | 收到合法状态包 |
| 已连接 | 收到合法状态包 | OLED 显示 `[OK]`、接收端电压、速度等；持续发送控制包 | 500ms 未收到合法状态包 |
| 低电量 | CW2015 SOC <= 20% | 首次进入时三短一长提示 | SOC > 25% |
| 严重低电量 | CW2015 SOC <= 10% | 每 1s 蜂鸣 500ms | SOC > 10% |

## 2. 接收端状态机

| 状态 | 进入条件 | 行为 | 退出条件 |
|---|---|---|---|
| 初始化 | 上电 | 初始化 PWM、LED、蜂鸣器、ESP-NOW、定时器、VESC UART，播放启动提示音 | 初始化流程完成 |
| 未连接 | 尚未收到合法控制包 | LED 500ms 慢闪；输出当前油门值，默认 throttle=0 | 收到合法控制包 |
| 已连接 | 收到合法控制包 | 更新 throttle、speedLevel、buttons；输出 PWM；20Hz 回传状态 | 超过 2000ms 未收到控制包 |
| 失控保护 | 2000ms 未收到控制包 | `throttle=0`；蜂鸣 1000ms；LED 100ms 快闪；状态包 bit0=1 | 再次收到合法控制包 |
| VESC 读取失败 | 每秒读取 VESC 失败 | 串口打印错误；保留已有电压和速度值 | 下次 VESC 读取成功 |

## 3. 关键状态转换

```text
发射端:
初始化 -> 未连接 -> 已连接 -> 未连接
                 -> 低电量/严重低电量报警

接收端:
初始化 -> 未连接 -> 已连接 -> 失控保护 -> 已连接
                 -> VESC 读取失败 -> 已连接
```
