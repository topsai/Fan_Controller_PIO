# Requirements Specification

## 1. 项目目标

将原 Arduino IDE 的两个可运行工程迁移到 VSCode + PlatformIO，保持硬件引脚和现有运行行为不变，并为后续重构、校准和测试建立文档基线。

- 发射端工程：`src/transmitter/main.cpp`
- 接收端工程：`src/receiver/main.cpp`
- PlatformIO 环境：`transmitter`、`receiver`
- 开发板：Espressif ESP32-C3-DevKitM-1
- framework：Arduino
- 通信方式：ESP-NOW
- 接收端控制对象：VESC

## 2. 已确认事实

| 项目 | 结论 |
|---|---|
| 两块 ESP32-C3 MAC | 以当前项目代码中写入的 MAC 为准 |
| 原 Arduino 代码状态 | 已经完全可运行 |
| 引脚定义 | 当前代码中的引脚设定确认可用 |
| 按钮 1 | 暂无功能，仅保留协议 bit |
| `StatusPacket.motorPWM[4]` | 冗余字段，当前无业务用途 |
| 接收端电压来源 | 只保留 VESC 电压，不保留 ADC 电压检测 |
| 发射端摇杆中心 | 后续需要开启中位校准 |
| 轮速系数 | `rpm * 0.00207` 已实测 |

## 3. 功能范围

### 发射端

| 模块 | 要求 |
|---|---|
| 摇杆输入 | 读取 ADC，将油门/刹车映射为 `-1000 ~ 1000` |
| 摇杆中位 | 当前代码固定 `ADC_CENTER=2048`；后续改为开机中位校准 |
| 三档开关 | 低电平有效，输出速度档位 1/2/3 |
| 按钮 | 按钮 1、按钮 2 低电平有效，20ms 消抖 |
| OLED | 显示连接状态、接收端电压、速度、档位、油门/刹车、本地电池 |
| 本地电池 | 通过 CW2015 读取电压和 SOC |
| 蜂鸣器 | 提供按键音、断线报警、低电量报警 |
| 控制发送 | 100Hz 发送控制包 |
| 状态接收 | 接收接收端回传的状态包 |

### 接收端

| 模块 | 要求 |
|---|---|
| ESP-NOW 接收 | 只接受绑定发射端 MAC 的合法控制包 |
| 油门输出 | 输出 50Hz PWM/Servo 信号给 VESC |
| 档位限幅 | 1档 500，2档 750，3档 1000 |
| 失控保护 | 超时未收到控制包时油门归零 |
| VESC 通信 | UART 115200 读取 VESC 数据 |
| 电压回传 | 使用 VESC 输入电压 |
| 速度回传 | 使用实测系数 `rpm * 0.00207` |
| 状态 LED | 显示收包、未连接、失控状态 |
| 蜂鸣器 | 失控提示；按钮 2 远程控制持续鸣叫 |

## 4. 非目标

当前阶段不做以下事情：

- 不更改已确认可用的硬件引脚。
- 不立即删除 `StatusPacket.motorPWM[4]`，除非进入协议清理阶段。
- 不引入接收端 ADC 电压检测。
- 不为按钮 1 绑定临时功能。
- 不改变已实测轮速系数。

## 5. 后续明确要做

| 优先级 | 事项 | 说明 |
|---|---|---|
| 高 | 发射端摇杆开机中位校准 | 上电时采样当前回中值作为中心，替代固定 2048 |
| 中 | 协议冗余字段清理 | 评估删除 `motorPWM[4]` 的兼容影响 |
| 中 | 自动化测试 | 抽离纯逻辑后补单元测试 |
| 低 | 文档随代码同步 | 每次行为变化后更新文档 |
