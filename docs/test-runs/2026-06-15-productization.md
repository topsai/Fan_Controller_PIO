## 断联修复追加记录

首次产品化烧录只把接收端升级到协议 v2，而遥控器仍可能运行 v1 固件。接收端原实现要求 `len == sizeof(ControlPacket)` 且必须有 `version/sequence/crc`，会把旧遥控器的 7 字节 v1 控制包直接丢弃，导致实机链路无法完成连接。

已追加修复：

- 接收端同时接受 v1 旧控制包和 v2 新控制包。
- v1 包使用旧累加和校验，v2 包继续使用 CRC-8 和序号防重放。
- 接收端识别到 v1 遥控器时回传旧 14 字节状态包，避免旧遥控器状态接收失败。
- 修复后重新上传接收端到 COM4，上传和 hash 校验通过。

## 后续人工观察点
