# 2026-06-08 Distinct Beep Frequencies

## 背景

原代码中多数提示音都使用 2000Hz，只能靠时长和节奏区分。实际使用时，断线、失控、远程蜂鸣、低电量等场景不够容易辨认。

## 方案

采用方案 1：只改频率，不改提示音节奏。

| 场景 | 频率 |
|---|---:|
| 按键提示 | 1800Hz |
| 开机提示 | 2200Hz |
| 链路异常/断线提示 | 1200Hz |
| 失控保护提示 | 900Hz |
| 按钮 2 远程蜂鸣 | 2600Hz |
| 发射端低电量提示 | 700Hz |

## 代码变更

- 新增 `include/beep_profiles.h` 统一维护频率常量。
- 发射端和接收端 `tone()` 调用改用具名频率常量。
- 保持原有提示音时长和节奏不变。

## 硬件验证建议

1. 重启两端，确认开机提示音为 2200Hz 两短鸣。
2. 按下发射端按钮，确认本地按键音为 1800Hz 短鸣。
3. 关闭发射端，确认接收端每 2 秒发出 1200Hz 短提示。
4. 按住按钮 2，确认接收端远程蜂鸣为 2600Hz，并在 3 秒左右自动停止。
5. 低电量提示需要通过实际低电量或后续模拟测试验证。

## 结论

代码层面已完成提示音频率区分，且保持原提示音节奏不变。实际听感仍以硬件蜂鸣器响应为准，如某个频率听起来不明显，可只调整 `include/beep_profiles.h` 中对应常量。
