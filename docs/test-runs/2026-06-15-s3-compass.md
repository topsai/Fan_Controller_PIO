# 2026-06-15 S3 Compass 指南针接入验证

## 目标

验证 S3 UI 新增的 `Compass` 图片组件已接入 QMC5883L 航向数据，并可编译上传到 COM3 上的 ESP32-S3。

## 结果

- `pio test -e native`：未通过启动阶段。当前 Windows 环境缺少 `gcc/g++`，PlatformIO native 环境无法编译测试程序；未进入 Unity 断言。
- `pio run -e s3_transmitter`：通过。
- `pio run -e s3_transmitter -t upload --upload-port COM3`：通过，固件已上传到 COM3 上的 ESP32-S3，写入后 hash 校验通过。

## 备注

- 本次新增的单测覆盖 `s3CompassAngleForHeading()`，用于校验 QMC 航向角归一化和 LVGL 图片角度单位转换。
- 本次验证没有做屏幕肉眼观察记录；如果后续发现箭头方向与实物期望相反，可在绑定层增加固定角度偏移或反向映射。
