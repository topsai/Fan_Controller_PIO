# 2026-06-15 S3 MCU 内部温度显示验证

## 目标

验证 SquareLine 新增的 `MCUTemp` Label 已接入 ESP32-S3 内部温度，并显示为一位小数摄氏温度，例如 `43.2C`。

## 结果

- `pio test -e native`：未通过启动阶段。当前 Windows 环境缺少 `gcc/g++`，PlatformIO native 环境无法编译测试程序；未进入 Unity 断言。
- `pio run -e s3_transmitter`：通过。
- `pio run -e s3_transmitter -t upload --upload-port COM3`：通过，固件已上传到 COM3 上的 ESP32-S3，写入后 hash 校验通过。

## 备注

- 本次新增 `s3FormatMcuTemperatureText()` 单测，覆盖有效读数一位小数格式和无效值 `--.-C`。
- 本次没有做屏幕目视确认记录；如果实际显示位置太挤，应在 SquareLine 中调整 `MCUTemp` 的位置或字号后重新导出。
