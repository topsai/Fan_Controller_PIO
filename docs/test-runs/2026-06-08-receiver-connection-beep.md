# 2026-06-08 Receiver Connection Beep

## 背景

遥控器蜂鸣器暂未接线，因此连接成功提示音先由接收端蜂鸣器发出。

## 行为定义

| 场景 | 是否提示 |
|---|---|
| 接收端上电后首次收到合法控制包 | 是 |
| 连接正常时持续收包 | 否 |
| 进入 failsafe 后重新收到合法控制包 | 是 |
| 未连接状态下恢复收到合法控制包 | 是 |

## 参数

| 参数 | 当前值 |
|---|---:|
| 连接成功频率 | 2400Hz |
| 连接成功时长 | 160ms |

## 实现说明

- ESP-NOW 接收回调只判断连接恢复边沿，并设置 `connectionBeepPending`。
- 主循环调用 `updateConnectionBeep()` 播放提示音。
- `buzzerHoldUntil` 用于保护带时长的提示音，避免同一轮 loop 后续 `noTone()` 立即打断。

## 硬件验证建议

1. 接收端上电。
2. 发射端上电并等待连接。
3. 期望：接收端发出一次 2400Hz 短提示音。
4. 保持连接正常。
5. 期望：接收端不重复播放连接成功音。
6. 关闭发射端并等待接收端进入链路异常/失控提示。
7. 重新打开发射端。
8. 期望：接收端再次发出一次 2400Hz 短提示音。
