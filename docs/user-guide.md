# User Guide

本文件面向实际使用和调试，说明这套发射端/接收端系统怎么开机、怎么操作、有哪些提示音和保护行为。

## 1. 系统组成

| 角色 | PlatformIO 环境 | 端口约定 | 作用 |
|---|---|---|---|
| C3 基础版发射端/遥控器 | `transmitter` | COM5 | 读取摇杆、三档开关、按钮、电池信息，通过 ESP-NOW 发送控制数据 |
| S3 高级发射端 | `s3_transmitter` | COM3 | 使用彩色触摸屏显示状态，兼容同一接收端协议 |
| 接收端/接收机 | `receiver` | COM4 | 接收控制数据，输出 PWM/Servo 给 VESC，读取 VESC 电压和转速并回传 |

## 2. 正常使用步骤

1. 确认接收端和 VESC 共地，VESC UART、PWM/Servo 信号线连接正常。
2. 打开发射端电源，保持摇杆自然回中。
3. 发射端上电时会自动采样摇杆中位，不要在刚开机时推动摇杆。
4. 上电后先保持摇杆回中，再将摇杆拉到最大刹车方向并保持约 3 秒完成解锁；未解锁前发出的 throttle 强制为 0。
5. 打开接收端电源。
6. 发射端 OLED 或 S3 屏幕显示 `[OK]` / `OK` 后表示已经收到接收端回传。
7. 推动摇杆控制油门/刹车。
8. 使用三档开关选择速度限幅。
9. 使用按钮 2 可以让接收端蜂鸣器响起；单次最长 3 秒，松开后可重新触发。

## 3. 发射端 OLED 显示

| 显示内容 | 含义 |
|---|---|
| `[OK]` | 已收到接收端状态包，链路正常 |
| `[LOST]` | 超过 500ms 未收到接收端状态包 |
| `BAT:x.xxV` 第一行 | 接收端/VESC 回传电压 |
| `SPD:n` | 当前速度档位 |
| `ARM` / `LOCK` | 发射端油门是否已解锁；`LOCK` 时需拉满刹车约 3 秒解锁 |
| `THR:xxxx` | 正向油门值 |
| `BRK:xxxx` | 反向/刹车值 |
| 大号 `xx KM` | 接收端回传速度 |
| `SOC:xxx% BAT:x.xxV` | 发射端本地 CW2015 电量和电压 |

## 4. 发射端操作

### 4.1 摇杆

| 操作 | 行为 |
|---|---|
| 自然回中 | 输出 throttle 约为 0 |
| 正向推动 | 输出 `0 ~ 1000` |
| 反向推动 | 输出 `0 ~ -1000` |

发射端每次上电会采样 64 次摇杆 ADC 作为中位。开机时不要触碰摇杆，否则中位会被校准偏。

油门输出带变化率限制，摇杆突然推到底时，实际发送 throttle 会按固定步进逐步接近目标值，避免瞬间大油门。

上电或退出设置页后，发射端处于锁定状态。解锁方式是把摇杆拉到最大刹车方向并保持约 3 秒，听到解锁提示音后才允许输出油门/刹车。

### 4.2 三档开关

| 档位 | 接收端 throttle 限幅 |
|---|---:|
| 1 档 | `-500 ~ 500` |
| 2 档 | `-750 ~ 750` |
| 3 档 | `-1000 ~ 1000` |

如果多个档位输入同时有效，优先级为 `3 > 2 > 1`。如果没有档位输入有效，默认 1 档。

### 4.3 按钮

| 按钮 | 当前功能 |
|---|---|
| 按钮 1 短按 | 进入/退出设置页面；进入设置页面后 throttle 强制为 0 |
| 按钮 1 长按 3 秒 | 发送主动接管请求；不进入设置页面 |
| 按钮 2 | 按下后接收端蜂鸣器响起；单次最长 3 秒，松开后可重新触发 |

两个按钮按下时，发射端本地会短鸣作为按键提示。

多遥控器同时开机时，接收端保持当前 active 控制源。另一台遥控器只有按钮1长按 3 秒发送接管请求后，才能切换控制权；切换时接收端先将输出归零，并重新等待 3 个合法控制包。

### 4.4 设置页面和摇杆校准

C3 OLED 版：

- 按按钮 1 进入/退出设置页面。
- 设置页面内控制输出锁定，发送 throttle 为 0。
- 设置页面内按按钮 2 执行摇杆中位校准。
- 退出设置页面后需要重新拉满刹车约 3 秒解锁。

S3 触摸版：

- 按按钮 1 进入/退出触摸设置页面。
- 设置页面内控制输出锁定，发送 throttle 为 0。
- 触摸 `CAL` 重新采样摇杆中位。
- 触摸 `-10` / `+10` 可微调摇杆中位。
- 触摸 `EXIT` 退出设置页面；退出后需要重新拉满刹车约 3 秒解锁。

## 5. 接收端行为

### 5.1 PWM/Servo 输出

接收端 GPIO4 输出 50Hz PWM/Servo 信号给 VESC。

| throttle | duty | 估算脉宽 |
|---:|---:|---:|
| `-1000` | 51 | 约 1.0ms |
| `0` | 76 | 约 1.5ms |
| `1000` | 102 | 约 2.0ms |

这符合常见 VESC PPM/Servo 输入范围。最终是否匹配实际 VESC 设置，以 VESC Tool 的 PPM 校准页面为准。

### 5.2 VESC 遥测

| 数据 | 来源 | 用途 |
|---|---|---|
| 输入电压 | VESC UART | 回传发射端 OLED 显示 |
| RPM | VESC UART | 换算速度 |
| 速度 | `rpm * 0.00207` | 已实测系数 |

接收端不再使用 ADC 读取电池电压。

## 6. 提示音和报警

### 6.1 发射端提示

| 场景 | 行为 |
|---|---|
| 开机 | 两次短鸣 |
| 按钮按下 | 1800Hz 短鸣 |
| 接收端断线 | 1200Hz 周期报警 |
| 发射端电量低于 20% | 700Hz 首次三短一长提示 |
| 发射端电量低于 10% | 700Hz 每 1 秒蜂鸣约 500ms |

### 6.2 接收端提示

| 场景 | 行为 |
|---|---|
| 开机 | 2200Hz 两次短鸣 |
| 遥控器连接成功/断线后恢复 | 2400Hz 短鸣一次 |
| 按钮 2 按下 | 2600Hz 远程蜂鸣，单次最长 3 秒 |
| 按钮 2 松开 | 停止蜂鸣，并复位远程蜂鸣超时保护 |
| 遥控器未打开/断电/失效 | 1200Hz 每 2 秒短促蜂鸣一次 |
| 进入失控保护 | throttle 清零，档位回 1，按钮清零，并用 900Hz 蜂鸣提示 |

已实测：手动关闭发射器后，接收端会发出短促间隔的滴滴声。

注意：按钮 2 的远程蜂鸣不是无限时长。如果接收端连续识别到按钮 2 按下超过 3 秒，会自动停止本次蜂鸣，并在串口输出 `远程蜂鸣超时保护，已停止`。需要再次蜂鸣时，先松开按钮 2 再重新按下。

## 7. 失控保护

接收端超过 2000ms 未收到合法控制包后进入失控保护。

进入失控保护时，接收端状态会统一设置为：

| 字段 | 安全值 |
|---|---|
| `throttle` | `0` |
| `speedLevel` | `1` |
| `buttons` | `0` |
| `connected` | `false` |
| `failsafeActive` | `true` |

此时 PWM 输出回到中位附近，约 1.5ms。

## 8. LED 状态

| 状态 | LED 行为 |
|---|---|
| 收到合法控制包 | 每次收包翻转 |
| 未连接 | 约 500ms 慢闪 |
| 失控保护 | 约 100ms 快闪 |

## 9. 常用 PlatformIO 命令

### 9.1 自动测试

```text
pio test -e native
```

### 9.2 编译

```text
pio run -e transmitter
pio run -e receiver
pio run -e s3_transmitter
```

### 9.3 上传固件

```text
pio run -e receiver -t upload --upload-port COM4
pio run -e transmitter -t upload --upload-port COM5
pio run -e s3_transmitter -t upload --upload-port COM3
```

### 9.4 串口查看

```text
pio device monitor -p COM4 -b 115200
pio device monitor -p COM5 -b 115200
pio device monitor -p COM3 -b 115200
```

## 10. 每次改代码后的固定流程

1. 运行 `pio test -e native`。
2. 运行 `pio run -e transmitter`。
3. 运行 `pio run -e receiver`。
4. 上传接收端到 COM4。
5. 上传 C3 基础版发射端到 COM5。
6. 如本轮涉及 S3，上传 S3 发射端到 COM3。
7. 做相关硬件复测。
8. 更新 `docs/progress.md`、`docs/bugs.md` 和 `docs/test-runs/`。
9. 提交并推送到 GitHub。

## 11. 常见问题

| 问题 | 检查方向 |
|---|---|
| OLED 显示 `[LOST]` | 检查接收端是否上电、MAC 是否匹配、两端是否同信道 |
| 接收端一直滴滴响 | 发射端可能未开机、断电、距离过远或 ESP-NOW 未连上 |
| 接收端出现长鸣 | 检查按钮 2 是否被按住或卡住；当前固件会在连续 3 秒后自动停止远程蜂鸣 |
| 摇杆回中不为 0 | 重新上电并确保开机时摇杆保持自然回中 |
| VESC 没响应 | 检查 GPIO4 PWM、VESC PPM/Servo 配置、共地和输入校准 |
| 没有 VESC 电压/速度 | 检查 UART 线序、波特率 115200、VESC 是否供电 |
| 串口没有应用日志 | 确认 `platformio.ini` 中启用了 `ARDUINO_USB_MODE=1` 和 `ARDUINO_USB_CDC_ON_BOOT=1` |
