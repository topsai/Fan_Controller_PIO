# 遥控器产品化功能记录

本文记录本轮成熟化改造已经落地的固件能力，以及仍需要实物和 UI 配合完成的事项。

## 已落地

- 摇杆校准持久化：S3 使用 NVS 保存 `center/min/max/deadzone`，启动优先读取保存值，无效时自动开机采样。
- 协议 v2：控制包和状态包增加 `version`、`sequence` 和 CRC8。
- 重放/倒序保护：接收端和发射端都会拒绝重复或倒退的状态/控制序号。
- 接收端安全门槛：接收端需要连续收到 3 个合法新鲜控制包后才进入连接输出状态。
- 接收端状态位：状态包回传 failsafe、VESC 遥测有效、协议错误、发射端锁定状态。
- S3 诊断数据：S3 统计状态包速率、估算丢包数、RSSI、接收端状态位和背光亮度状态。
- 电源管理：S3 触摸屏 30 秒无用户活动后降低背光，触摸、按钮或摇杆活动恢复亮度。
- 传感器实用化：MCU 温度加入过温告警判断；指南针保持有效/无效透明度策略；BMP280 保持可信读数过滤。

## 需要 UI 组件后继续绑定

本轮固件已经准备好数据字段，但为了不手写 SquareLine 生成层，新增诊断页面和系统页面需要先在 SquareLine 中添加组件。组件清单见 `docs/s3-ui-final-components.md`。

## 需要实物复测

- S3 保存校准后断电重启，确认中位仍然稳定。
- 接收端 COM4 上传后，确认 v2 协议下 C3/S3 发射端都能控制。
- 断开发射端，确认接收端进入 failsafe 并在状态包中置位。
- 拔掉或关闭 VESC UART，确认 VESC 遥测有效位清除。
- 长时间运行 10 分钟，观察 MCU 温度、背光降亮度和触摸唤醒。
