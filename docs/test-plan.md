# Test Plan

## 1. 编译测试

| 步骤 | 命令 | 期望 |
|---|---|---|
| 编译发射端 | `pio run -e transmitter` | 编译通过 |
| 编译接收端 | `pio run -e receiver` | 编译通过 |
| 清理后全量编译 | `pio run -t clean && pio run` | 两个环境均通过 |

## 2. 烧录测试

| 目标 | 命令 | 期望 |
|---|---|---|
| 发射端 | `pio run -e transmitter -t upload` | 烧录成功，串口输出启动信息 |
| 接收端 | `pio run -e receiver -t upload` | 烧录成功，串口输出启动信息 |

## 3. 发射端单板测试

| 编号 | 测试项 | 步骤 | 期望 |
|---|---|---|---|
| TX-01 | OLED 初始化 | 发射端上电 | 显示初始化画面 |
| TX-02 | CW2015 检测 | 查看串口和 OLED | 能显示本地电压/SOC；无模块时显示 N/A 且系统继续运行 |
| TX-03 | 摇杆回中 | 摇杆自然回中 | throttle 接近 0 |
| TX-04 | 摇杆满量程 | 前后推动摇杆 | throttle 在 `-1000 ~ 1000` 范围变化 |
| TX-05 | 三档开关 | 切换 1/2/3 档 | OLED `SPD` 对应变化 |
| TX-06 | 按钮 1 | 按下和松开 | bit0 变化，发射端短鸣 |
| TX-07 | 按钮 2 | 按下和松开 | bit1 变化，发射端短鸣 |
| TX-08 | 未连接报警 | 只开发射端 | 500ms 后显示 `[LOST]`，蜂鸣报警 |

## 4. 接收端单板测试

| 编号 | 测试项 | 步骤 | 期望 |
|---|---|---|---|
| RX-01 | 启动 | 接收端上电 | 串口输出本机 MAC 和绑定 MAC |
| RX-02 | 未连接 LED | 不打开或远离发射端 | LED 约 500ms 慢闪 |
| RX-03 | PWM 初始输出 | 测量 GPIO4 | 50Hz，默认接近中位 |
| RX-04 | VESC UART | 连接 VESC 后观察串口 | 每秒能读取 VESC 数据；失败时输出错误 |

## 5. 联调测试

| 编号 | 测试项 | 步骤 | 期望 |
|---|---|---|---|
| INT-01 | 配对连接 | 两端上电 | 发射端 OLED 从 `[LOST]` 变 `[OK]` |
| INT-02 | 控制链路 | 推动摇杆 | 接收端 PWM 随 throttle 变化 |
| INT-03 | 档位限幅 | 分别切换 1/2/3 档并推满摇杆 | 接收端限幅分别为 500/750/1000 |
| INT-04 | 按钮 2 远程蜂鸣 | 按住发射端按钮 2 | 接收端蜂鸣器持续响，松开停止 |
| INT-05 | 遥测电压 | VESC 连接并供电 | 发射端显示接收端/VESC 电压 |
| INT-06 | 遥测速度 | 转动电机或模拟 VESC RPM | 发射端速度显示按实测系数变化 |
| INT-07 | 接收端失控保护 | 关闭发射端 | 接收端约 2s 后 throttle=0，LED 快闪，蜂鸣 |
| INT-08 | 发射端断线报警 | 关闭接收端 | 发射端约 500ms 后 `[LOST]` 并报警 |
| INT-09 | 恢复连接 | 重新打开被关闭的一端 | 自动恢复连接和正常控制 |

## 6. 回归测试触发条件

以下变更后必须执行联调测试：

- ESP-NOW 协议字段变化。
- MAC 绑定逻辑变化。
- PWM 映射或限幅变化。
- 失控保护逻辑变化。
- VESC 读取逻辑变化。
- 摇杆中位校准逻辑变化。
- 任意硬件引脚变化。
