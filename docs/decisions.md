# Design Decisions

## DEC-001: 以当前代码中的 MAC 为真实 MAC

- 日期：2026-06-07
- 决策：两块 ESP32-C3 的真实 MAC 以当前项目代码中写入的值为准。
- 影响：文档和后续迁移不再把 MAC 作为待确认项。

## DEC-002: 当前引脚定义保持不变

- 日期：2026-06-07
- 决策：原 Arduino 代码已经完全可运行，当前引脚设定确认没问题。
- 影响：迁移到 PIO 时不调整引脚。

## DEC-003: 按钮 1 暂无业务功能

- 日期：2026-06-07
- 决策：按钮 1 只保留协议 bit，不绑定临时功能。
- 影响：接收端目前不对按钮 1 做动作。

## DEC-004: 接收端电压只使用 VESC 遥测

- 日期：2026-06-07
- 决策：接收端不保留 ADC 电压检测。
- 影响：后续清理代码时可删除接收端 ADC 电压检测残留注释或旧逻辑。

## DEC-005: 发射端需要摇杆开机中位校准

- 日期：2026-06-07
- 决策：固定 `ADC_CENTER=2048` 不作为最终方案，后续实现开机采样校准。
- 影响：测试计划需覆盖校准后中位稳定性。

## DEC-006: 轮速系数已实测

- 日期：2026-06-07
- 决策：保留 `speed = rpm * 0.00207`。
- 影响：除非重新实测，不修改该系数。

## DEC-007: `StatusPacket.motorPWM[4]` 是冗余字段

- 日期：2026-06-07
- 决策：该字段当前无业务用途。
- 影响：短期可保留以降低变更风险；协议清理阶段可删除。
